# 小鹿医助 · 微信小程序

把小鹿的核心能力搬进微信：手机号登录、按时间翻档案、只按档案回答。工程是原生小程序，无 npm、无框架，直接可编译。

## 目录

```
app.json / app.js / app.wxss     全局配置与主题
project.config.json              开发者工具工程配置（appid 目前是 touristappid）
assets/deer-512.png              应用内头像（512，已裁掉水印与卡片白边）
assets/deer-144.png              小程序头像上传用（144）
utils/api.js                     请求封装：带 X-Xiaolu-Token、自动拼 sharecode
utils/config.js                  后端地址与访问码（要改就改这里）
pages/index                      首页：未登录引导 / 已登录看最近一次记录
pages/login                      手机号 + 密码登录，可切「创建新账号」
pages/records                    就诊记录列表（下拉刷新）
pages/detail                     单条记录详情：用药、复诊、过敏、注意事项、原始转写
pages/ask                        询问：快捷提问 + 发送，只答档案里的内容
pages/mine                       我的：头像、手机号、记录数、退出
```

底部三个入口：记录 / 询问 / 我的。首页不在 tabBar 里，登录后落到首页，再进各页。

## 数据从哪来

不新起一套账号，直接复用现有 FastAPI（`utils/config.js` 里的 `apiBase`）：

- 登录：`POST /api/auth/login`，body `{phone, password}`
- 注册：`POST /api/auth/register`，body `{username, phone, password}`
- 档案：`GET /api/records`、`GET /api/records/{id}`
- 问答：`POST /api/chat/sync`，body `{question}`

所以网页版那三个账号（陈子菱、费佳、贾发奥）在小程序里用同一手机号和密码就能登，看到的是同一份档案。

## 上线前必须做的一步：配置请求域名

小程序不允许请求未备案的域名。在微信公众平台（或 WorkBuddy 的小程序发布面板）找到：

**开发 → 开发设置 → 服务器域名 → request 合法域名**

把 `https://xiaolu-medrec.app.workbuddy.host` 加进去。没加的话真机会报：

> 不在以下 request 合法域名列表中

本地开发阶段可以先在开发者工具里勾「不校验合法域名」（详情 → 本地设置）。

## 怎么跑起来

### 方式一：微信开发者工具（本机预览最直接）

1. 安装微信开发者工具，导入目录 `xiaolu-miniprogram`
2. AppID 可以先用「测试号」，也可以填你自己的小程序 AppID
3. 编译后即可在模拟器里登录、翻档案、提问

本机目前没有安装开发者工具，所以这一步没有在这里执行过。

### 方式二：WorkBuddy 小程序入口

用「代码开发 → 小程序」新建一个任务，把 `xiaolu-miniprogram` 作为项目打开，
可以在预览面板里直接看效果，并从右上角「分享」进入试用 / 绑定 / 上传 / 提审 / 发布。

> 注意：当前工作区已经绑定了一个**网页应用**，平台不允许把小程序目录挂到那个应用上，
> 所以在这里注册小程序应用卡会失败（提示应用类型不是 miniprogram）。换一个小程序任务/工作区即可。

## 关于「扫之前的二维码」和「搜索小鹿医助」

这两件事有平台前提，不是改代码能绕过的：

| 需求 | 现状 | 怎么才能做到 |
| --- | --- | --- |
| 扫之前那张二维码打开小程序 | 那张码里是网页地址（`.../app.html?sharecode=...`），扫码只会打开网页版 | 小程序**发布后**，在微信后台「推广 → 小程序码」生成新的码，替换旧的 |
| 微信搜索「小鹿医助」打开 | 需要小程序已发布，且名称通过审核 | 发布后到微信后台设置名称；「小鹿医助」是否被占用要在后台查，占用就得换名（如「小鹿病历助手」） |

在小程序发布并生成小程序码之前，旧二维码仍然指向网页版，这是正常的。

## 已知边界

- 小程序端**没有做录音整理**（微信录音 + 转写要走服务端 ASR，属于下一步）；录音与拍照识药仍在网页版
- 头像与身份证号这些本机字段不参与同步，小程序只展示服务端资料
- 内容只复述档案，不构成诊疗建议
